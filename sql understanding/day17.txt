FULL OUTER JOIN
Give me everything from both tables, whether there is a match or not.

3. RIGHT JOIN
What is RIGHT JOIN?
A RIGHT JOIN returns:
✅ All rows from the right table
✅ Matching rows from the left table
✅ NULL when there is no matching row
Syntax:
SELECT columns
FROM table1
RIGHT JOIN table2
ON table1.column = table2.column;

4. Simple Example
Let's put employees_join on the left and departments on the right:
SELECT
   e.name,
   d.department_name
FROM employees_join e
RIGHT JOIN departments d
ON e.department_id = d.department_id;
The important thing is:
employees_join = LEFT
departments    = RIGHT
Therefore:
Keep ALL departments.

5. RIGHT JOIN in SQLite
This is important for you because you're using SQLite.
Modern SQLite versions support:
RIGHT JOIN
So this works in current SQLite:
SELECT
   e.name,
   d.department_name
FROM employees_join e
RIGHT JOIN departments d
ON e.department_id = d.department_id;
However, if your SQLite extension/environment doesn't support RIGHT JOIN, you can simply reverse the tables and use LEFT JOIN.
For example:
SELECT
   e.name,
   d.department_name
FROM departments d
LEFT JOIN employees_join e
ON d.department_id = e.department_id;
This gives the same logical result.
⭐ Remember this trick
A RIGHT JOIN B

is logically equivalent to

B LEFT JOIN A
This is extremely useful when working with databases that don't support RIGHT JOIN.

8. RIGHT JOIN vs LEFT JOIN
Let's make it very simple.
LEFT JOIN
FROM employees e

Means:

RIGHT JOIN
FROM employees e

Means:
Keep all departments.
So Marketing appears.

9. FULL OUTER JOIN
Now we reach one of the most important concepts.
What is FULL OUTER JOIN?
FULL OUTER JOIN returns:
All matching and unmatched rows from both tables.
So:
LEFT JOIN
+
RIGHT JOIN
=
FULL OUTER JOIN
Conceptually.

11. FULL OUTER JOIN in SQLite
Modern SQLite versions support:
FULL OUTER JOIN
So you can try:
SELECT
   e.name,
   d.department_name
FROM employees_join e
FULL OUTER JOIN departments d
ON e.department_id = d.department_id;
But here's an important interview point:
Older SQLite versions did not support FULL OUTER JOIN.
The traditional SQLite solution is:
SELECT
   e.name,
   d.department_name
FROM employees_join e
LEFT JOIN departments d
ON e.department_id = d.department_id

UNION

SELECT
   e.name,
   d.department_name
FROM departments d
LEFT JOIN employees_join e
ON d.department_id = e.department_id;
This combines:
LEFT JOIN
+
reverse LEFT JOIN
to simulate a FULL OUTER JOIN.

12. Why UNION?
Suppose the first query gives:
All employees + matching departments
and the second query gives:
All departments + matching employees
Some rows appear in both.
UNION removes duplicates.
Therefore we get the equivalent of:
FULL OUTER JOIN

🧠 Interview Questions
Q1. What is RIGHT JOIN?
Answer:
RIGHT JOIN returns all rows from the right table and matching rows from the left table. If no match exists, columns from the left table contain NULL.

Q2. What is FULL OUTER JOIN?
Answer:
FULL OUTER JOIN returns all rows from both tables. Matching rows are combined, while unmatched rows contain NULLvalues for the other table.

Q3. Difference between LEFT JOIN and RIGHT JOIN?
Answer:
The difference is which table's unmatched rows are preserved.
LEFT JOIN  → preserves LEFT table
RIGHT JOIN → preserves RIGHT table

Q4. What does FULL OUTER JOIN return?
Answer:
It returns:
Matching rows
+
Unmatched rows from left
+
Unmatched rows from right

Q5. Does SQLite support RIGHT JOIN?
Answer:
Modern SQLite versions support RIGHT JOIN. If you're using an older SQLite version that doesn't, you can reverse the tables and use LEFT JOIN.

Q6. Does SQLite support FULL OUTER JOIN?
Answer:
Modern SQLite versions support FULL OUTER JOIN. For older versions, it can be simulated using LEFT JOIN + UNION + a reversed LEFT JOIN.

Q7. How can you simulate RIGHT JOIN using LEFT JOIN?
Answer:
Reverse the tables.
Instead of:
A RIGHT JOIN B
use:
B LEFT JOIN A

Q8. How can you simulate FULL OUTER JOIN in older SQLite?
Answer:
Use two LEFT JOINs combined with UNION.
SELECT ...
FROM A
LEFT JOIN B ...

UNION

SELECT ...
FROM B
LEFT JOIN A ...;
