1. UPPER()
What is UPPER()?
Converts text to uppercase.

Syntax
SELECT UPPER(column_name)
FROM table_name;

Example
SELECT
name,
UPPER(name) AS Upper_Name
FROM employees_string;
Output
name
Upper_Name
Rahul
RAHUL
Amit
AMIT
Neha
NEHA


Real-Life Use
Imagine all names should appear in capital letters in a report.
rahul

↓

RAHUL

2. LOWER()
Converts text to lowercase.

Example
SELECT
name,
LOWER(name) AS Lower_Name
FROM employees_string;
Output
name
Lower_Name
Rahul

Amit
amit


Real-Life Use
Emails are often stored in lowercase.

5. CONCAT()
Used to join strings.

MySQL
SELECT CONCAT(name,' - ',department)
FROM employees_string;

SQLite
The preferred way is:
SELECT
name || ' - ' || department AS Employee_Details
FROM employees_string;
Output
Rahul - IT

Amit - HR

Interview Tip
If you're in a SQLite interview, use:
||
If you're in MySQL, PostgreSQL, or SQL Server interviews, CONCAT() is widely accepted (though PostgreSQL also supports ||).

Interview Questions (with Answers)
1. What does UPPER() do?
Answer:
Converts a string to uppercase.

2. What does LOWER() do?
Answer:
Converts a string to lowercase.

3. What is the difference between LENGTH() and LEN()?
Answer:
LENGTH() → SQLite, MySQL, PostgreSQL
LEN() → SQL Server

4. What is the difference between SUBSTR() and SUBSTRING()?
Answer:
SQLite mainly uses SUBSTR().
MySQL, PostgreSQL, and SQL Server use SUBSTRING() (PostgreSQL also supports SUBSTR()).

5. What does TRIM() do?
Answer:
Removes leading and trailing spaces from a string.

6. How do you concatenate strings in SQLite?
Answer:
Use the || operator.
Example:
SELECT name || ' - ' || department
FROM employees_string;
