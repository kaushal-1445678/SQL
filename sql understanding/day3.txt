1. DISTINCT
What is DISTINCT?
DISTINCT removes duplicate values from the result.
Imagine you ask:
"What departments are there in the company?"
You don't want:
IT
HR
IT
Sales
Finance
HR
You only want unique department names.
Syntax
SELECT DISTINCT column_name
FROM table_name;
Example 1
SELECT DISTINCT department
FROM employees;
Output
department
IT
HR
Sales
Finance
Notice:
IT appears only once
HR appears only once
Without DISTINCT
SELECT department
FROM employees;
Output
IT
HR
IT
Sales
Finance
HR
Duplicates are shown.
DISTINCT on Multiple Columns
SELECT DISTINCT department, salary
FROM employees;
Now SQL removes duplicate department + salary combinations.
It does not remove duplicates from each column separately.

2. ORDER BY
Suppose HR asks:
Show employees from highest salary to lowest salary.
Without ORDER BY, SQL may return rows in any order.
Syntax
SELECT *
FROM employees
ORDER BY column_name;
ASC (Ascending)
Ascending means:
Small → Large
A → Z
1 → 100
Example
SELECT *
FROM employees
ORDER BY salary ASC;
Output
Salary
40000
45000
50000
55000
70000
90000
ASC is the default.
So this is also correct:
SELECT *
FROM employees
ORDER BY salary;
DESC (Descending)
Descending means:
Large → Small
Z → A
100 → 1
Example
SELECT *
FROM employees
ORDER BY salary DESC;
Output
Salary
90000
70000
55000
50000
45000
40000
Order by Name
SELECT *
FROM employees
ORDER BY name ASC;
Output

Neha
Priya
Rahul
Rohit
Vikas
Order by Age
SELECT *
FROM employees
ORDER BY age DESC;
Oldest employee comes first.
Sorting by Multiple Columns
Suppose two employees have the same department.
First sort by department.
Then within each department sort by salary.
SELECT *
FROM employees
ORDER BY department ASC,
         salary DESC;

Interview Questions
1. What is DISTINCT?
Answer:
DISTINCT returns only unique values by removing duplicate rows from the query result.
2. Does DISTINCT modify the table?
Answer:
No. It only affects the result returned by the query.
3. What is ORDER BY?
Answer:
ORDER BY sorts the query result in ascending or descending order based on one or more columns.
4. What is the default sorting order?
Answer:
Ascending (ASC).
So these are equivalent:
ORDER BY salary;
ORDER BY salary ASC;
5. What is the difference between ASC and DESC?
Answer:
ASC → Lowest to highest, A to Z.
DESC → Highest to lowest, Z to A.
6. What is LIMIT?
Answer:
LIMIT restricts the number of rows returned by the query. It's commonly used for pagination and fetching the top N records.
7. What is TOP?
Answer:
TOP is used in SQL Server to limit the number of rows. In SQLite and MySQL, LIMIT is used instead.
8. How do you find the highest salary?
Answer:
SELECT *
FROM employees
ORDER BY salary DESC
LIMIT 1;
9. How do you find the top 5 highest-paid employees?
Answer:
SELECT *
FROM employees
ORDER BY salary DESC
LIMIT 5;
10. Can ORDER BY sort multiple columns?
Answer:
Yes.
Example:
SELECT *
FROM employees
ORDER BY department ASC,
         salary DESC;
This sorts by department first, then by salary within each department.
