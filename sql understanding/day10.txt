What are Aggregate Functions?
Suppose your manager asks:
How many employees are there?
What is the total salary?
What is the average salary?
Who earns the highest salary?
You don't need every row.
You need one summarized answer.
That's exactly what aggregate functions do.

1. COUNT()
What is COUNT()?
It counts rows.

Syntax
SELECT COUNT(*)
FROM employees;

Example 1: Count all employees
SELECT COUNT(*)
FROM employees;
Output
COUNT(*)
6

There are 6 employees.

COUNT(column_name)
SELECT COUNT(salary)
FROM employees;
Output:
COUNT(salary)
6

Since every employee has a salary, the answer is also 6.

Important Difference
Let's use the employees_null table.
name
email
Rahul
rahul@gmail.com
Amit
NULL
Neha
neha@gmail.com
Priya
NULL
Vikas
''

Example
SELECT COUNT(email)
FROM employees_null;
Output:
COUNT(email)
3

Why 3?
Because COUNT(column) does not count NULL values.
It counts:
Rahul ✅
Neha ✅
Vikas ('') ✅ (empty string is not NULL)
It skips:
Amit ❌
Priya ❌

COUNT(*)
SELECT COUNT(*)
FROM employees_null;
Output:
COUNT(*)
5

COUNT(*) counts every row, including rows containing NULL values.

Interview Question
Difference between COUNT(*) and COUNT(column)?
COUNT(*)
COUNT(column)
Counts all rows
Counts only non-NULL values


2. SUM()
What is SUM()?
Adds all numeric values together.

Syntax
SELECT SUM(salary)
FROM employees;

Example
SELECT SUM(salary)
FROM employees;
Calculation:
50000
45000
70000
40000
90000
55000
-------
350000
Output:
SUM(salary)
350000


3. AVG()
What is AVG()?
Returns the average value.

Example
SELECT AVG(salary)
FROM employees;
Calculation:
350000 ÷ 6
= 58333.33
Output:
AVG(salary)
58333.33


AVG ignores NULL
Suppose salaries are:
50000
NULL
70000
Average becomes:
(50000 + 70000) / 2
NOT
120000 / 3
NULL values are ignored.

4. MIN()
What is MIN()?
Returns the smallest value.

Example
SELECT MIN(salary)
FROM employees;
Output:
MIN(salary)
40000

Priya has the lowest salary.

Another Example
SELECT MIN(age)
FROM employees;
Output:
MIN(age)
25


5. MAX()
What is MAX()?
Returns the largest value.

Example
SELECT MAX(salary)
FROM employees;
Output:
MAX(salary)
90000


Another Example
SELECT MAX(age)
FROM employees;
Output:
MAX(age)
35


Aggregate Functions with WHERE
You can filter rows before applying the aggregate.

Example
Total salary of IT employees.
SELECT SUM(salary)
FROM employees
WHERE department = 'IT';
Calculation:
50000
70000
-------
120000
Output:
SUM(salary)
120000


Average salary in HR.
SELECT AVG(salary)
FROM employees
WHERE department = 'HR';
Output:
(45000 + 55000) / 2 = 50000

Highest salary in Finance.
SELECT MAX(salary)
FROM employees
WHERE department = 'Finance';
Output:
90000

Using Aliases
Instead of:
SELECT AVG(salary)
FROM employees;
Use:
SELECT AVG(salary) AS Average_Salary
FROM employees;
Output:
Average_Salary
58333.33

This makes reports easier to read.

Interview Questions (with Answers)
1. What are aggregate functions?
Answer:
Aggregate functions perform calculations on multiple rows and return a single result.
Examples: COUNT(), SUM(), AVG(), MIN(), MAX().

2. What is the difference between COUNT(*) and COUNT(column)?
Answer:
COUNT(*) counts all rows.
COUNT(column) counts only non-NULL values in that column.

3. Does AVG() include NULL values?
Answer:
No. AVG() ignores NULL values.

4. Which aggregate function finds the highest value?
Answer:
MAX()

5. Which aggregate function finds the smallest value?
Answer:
MIN()

6. Can aggregate functions be used with WHERE?
Answer:
Yes. WHERE filters rows first, and then the aggregate function is applied to the remaining rows.
Example:
SELECT SUM(salary)
FROM employees
WHERE department = 'IT';
