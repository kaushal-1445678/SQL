SELECT CURRENT_DATE;

2️⃣ Current Time
SQLite
SELECT TIME('now');
Output
18:40:10
SQLite returns UTC by default.
To get your local system time:
SELECT TIME('now','localtime');

3️⃣ Current Date & Time
SQLite
SELECT DATETIME('now');
or
SELECT DATETIME('now','localtime');
Output
2026-07-31 23:58:20

MySQL
SELECT NOW();

SQL Server
SELECT GETDATE();

4️⃣ DATEADD()
SQLite does not have DATEADD().
Instead use modifiers.
Add 10 days.
SQLite
SELECT DATE('2024-01-10','+10 days');
Output
2024-01-20

Subtract 5 days
SELECT DATE('2024-01-10','-5 days');
Output
2024-01-05

Add 2 months
SELECT DATE('2024-01-10','+2 months');
Output
2024-03-10

Add 1 year
SELECT DATE('2024-01-10','+1 year');
Output
2025-01-10

SQL Server
SELECT DATEADD(day,10,'2024-01-10');

MySQL
SELECT DATE_ADD('2024-01-10',INTERVAL 10 DAY);

⭐ Interview Tip
If the interviewer asks:
How do you add 30 days?
Answer according to the database.
SQLite
DATE(date,'+30 days')
SQL Server
DATEADD(day,30,date)
MySQL
DATE_ADD(date,INTERVAL 30 DAY)

5️⃣ DATEDIFF()
SQLite has no DATEDIFF().
Instead use
JULIANDAY()
Difference between two dates.
SELECT JULIANDAY('2024-01-20')
-
JULIANDAY('2024-01-10');
Output
10
Meaning
10 days

SQL Server
SELECT DATEDIFF(day,'2024-01-10','2024-01-20');

MySQL
SELECT DATEDIFF('2024-01-20','2024-01-10');

Find Days Since Joining
SQLite
SELECT
name,
ROUND(JULIANDAY('now')-JULIANDAY(joining_date)) AS Days_Worked
FROM employees_date;
This calculates how many days each employee has worked.

6️⃣ EXTRACT()
SQLite doesn't support EXTRACT().
Instead use
STRFTIME()

Extract Year
SQLite
SELECT
name,
STRFTIME('%Y',joining_date)
FROM employees_date;
Output
name
Year
Rahul
2022
Amit
2021


Extract Month
SELECT
name,
STRFTIME('%m',joining_date)
FROM employees_date;
Output
01
08
03

Extract Day
SELECT
name,
STRFTIME('%d',joining_date)
FROM employees_date;

MySQL/PostgreSQL
SELECT EXTRACT(YEAR FROM joining_date);

STRFTIME()
This is SQLite's most powerful date function.
Common formats
Format
Meaning

%m

Example
SELECT STRFTIME('%Y-%m','now');
Output
2026-07

Current Year
SELECT STRFTIME('%Y','now');
Output
2026

Current Month
SELECT STRFTIME('%m','now');

Current Day
SELECT STRFTIME('%d','now');

Mini Challenge (with Answers)
Q1 Find employees who joined in 2022.
SELECT *
FROM employees_date
WHERE STRFTIME('%Y',joining_date)='2022';

Q2 Find employees who joined in January.
SELECT *
FROM employees_date
WHERE STRFTIME('%m',joining_date)='01';

Q3 Show current year.
SELECT STRFTIME('%Y','now');

Q4 Add 100 days to every joining date.
SELECT
name,
DATE(joining_date,'+100 days')
FROM employees_date;

Q5 Find employees working for more than 1000 days.
SELECT
name,
ROUND(JULIANDAY('now')-JULIANDAY(joining_date))
AS Days_Worked
FROM employees_date
WHERE JULIANDAY('now')-JULIANDAY(joining_date) > 1000;
