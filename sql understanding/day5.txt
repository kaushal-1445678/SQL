What is DDL?
DDL stands for Data Definition Language.
DDL commands are used to create or change the structure of database objects like tables.
Think of building a house:
CREATE → Build a new house
ALTER → Add a new room
RENAME → Change the house name
DROP → Demolish the house
Notice these commands work on the structure, not just the data.

1. CREATE
What is CREATE?
CREATE is used to create a new database object.
Examples:
Table
Database (not in SQLite)
View
Index

Syntax
CREATE TABLE table_name (
    column1 datatype,
    column2 datatype
);

Example
CREATE TABLE students (
    id INTEGER PRIMARY KEY,
    name TEXT,
    age INTEGER
);
Now check your tables:
.tables

students

Important Note
SQLite does not support every ALTER operation that MySQL or SQL Server supports.
For interviews, you should know these common operations:
ALTER TABLE employees
ADD COLUMN email VARCHAR(100);
ALTER TABLE employees
DROP COLUMN email;
ALTER TABLE employees
MODIFY COLUMN salary BIGINT;
The last two are not supported directly in SQLite, but they are common interview questions.

4. TRUNCATE
What is TRUNCATE?
TRUNCATE removes all rows from a table.
But...
The table itself still exists.
Think of it like this:
A classroom
Before

Only the students are gone.

SQLite
SQLite does not support:
TRUNCATE TABLE students;
You'll get an error.
Instead, use:
DELETE FROM students;
to remove all rows.

Interview Questions
1. What is DDL?
Answer:
DDL (Data Definition Language) consists of SQL commands used to create, modify, rename, and delete database objects such as tables.

2. What is CREATE?
Answer:
CREATE is used to create new database objects like tables, views, and indexes.

3. What is ALTER?
Answer:
ALTER modifies the structure of an existing table, such as adding a new column or renaming the table.

4. What is DROP?
Answer:
DROP permanently removes both the table and all of its data.

5. What is TRUNCATE?
Answer:
TRUNCATE removes all rows from a table while keeping the table structure intact. (Not supported in SQLite.)

6. What is the difference between DROP and TRUNCATE?
Answer:
DROP removes both the table and its data.
TRUNCATE removes only the data; the table structure remains.

7. Does SQLite support TRUNCATE?
Answer:
No. In SQLite, use:
DELETE FROM table_name;
to remove all rows.
