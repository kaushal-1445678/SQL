1. What is a Self Join?
A Self Join means:
Joining a table with itself.
Normal JOIN:
employees  + departments
Self Join:
employees + employees
Same table, two roles.

5. Why Aliases Are Important
Since we use the same table twice:
employees_self
employees_self
SQL gets confused.
So we create aliases:
e = Employee

m = Manager
Think:
employees_self e
employees_self m
Actually:
Employee Table → e
Manager Table → m
Even though both are the same table.

6. First Self Join
Show employee name and manager name.
SELECT
   e.name AS Employee,
   m.name AS Manager
FROM employees_self e
INNER JOIN employees_self m
ON e.manager_id = m.emp_id;

How It Works
For Amit:
manager_id = 1
Manager table:
emp_id = 1 → Rahul
Match:
1 = 1

10. Find Managers Having More Than One Employee
SELECT
   m.name,
   COUNT(e.emp_id) AS Total
FROM employees_self m
LEFT JOIN employees_self e
ON e.manager_id = m.emp_id
GROUP BY m.name
HAVING COUNT(e.emp_id) > 1;

Interview Questions
1. What is a Self Join?
Answer:
A Self Join is a join where a table is joined with itself.

2. Why is Self Join used?
Answer:
To represent hierarchical relationships like:
Employee → Manager
Parent → Child
Category → Subcategory

3. Why are aliases necessary?
Answer:
Because the same table is used twice, aliases help SQL distinguish between the two roles.
Example:
e = Employee
m = Manager

4. Difference between INNER SELF JOIN and LEFT SELF JOIN?
INNER SELF JOIN
Returns only employees who have managers.
LEFT SELF JOIN
Returns all employees, including those without managers.

5. How do you find employees without managers?
SELECT e.name
FROM employees_self e
LEFT JOIN employees_self m
ON e.manager_id = m.emp_id
WHERE m.emp_id IS NULL;
