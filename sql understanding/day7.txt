Section F – Interview Theory
Q38. What is SQL?
Answer:
SQL (Structured Query Language) is a language used to create, retrieve, update, delete, and manage data stored in relational databases.

Q41. Why is WHERE important in UPDATE?
Without WHERE, every row in the table is updated.
Example:
UPDATE employees
SET salary = 100000;
All employees now have a salary of ₹100,000.

Q42. Why is WHERE important in DELETE?
Without WHERE, every row in the table is deleted.
DELETE FROM employees;
The table becomes empty.

Q43. What is the purpose of DISTINCT?
DISTINCT removes duplicate values from the query result.
Example:
SELECT DISTINCT department
FROM employees;

Q44. What is the purpose of ORDER BY?
ORDER BY sorts the query result in ascending (ASC) or descending (DESC) order.

Q45. Difference between ASC and DESC?
ASC → Small to large, A to Z (default)
DESC → Large to small, Z to A

Q46. What is the purpose of LIMIT?
LIMIT restricts the number of rows returned by a query.
Example:
SELECT *
FROM employees
LIMIT 5;

Q47. What is an alias in SQL?
An alias is a temporary name given to a column or table to improve readability.
Example:
SELECT salary AS Salary
FROM employees;

Q48. Why are table aliases useful?
Table aliases make queries shorter and are especially useful when working with joins.
Example:
SELECT e.name, e.salary
FROM employees AS e;
