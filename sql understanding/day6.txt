What is DML?
DML stands for Data Manipulation Language.
Unlike DDL (which changes the table structure), DML changes the data inside the table.
Think of a notebook:
DDL → Create or change the notebook.
DML → Write, edit, or erase the notes inside it.

1. INSERT
What is INSERT?
INSERT is used to add new rows into a table.
Think of adding a new employee to the company database.

Syntax
INSERT INTO table_name
VALUES (...);

Example 1
INSERT INTO employees
VALUES (7,'Ankit',27,'Marketing',60000);
Now check:
SELECT * FROM employees;
You'll see a new employee has been added.

Example 2 (Recommended)
Always specify the column names.
INSERT INTO employees
(id, name, age, department, salary)
VALUES
(8,'Simran',24,'HR',48000);
This is safer because it still works if the table structure changes later.

2. UPDATE
What is UPDATE?
UPDATE changes existing data.
Imagine Rahul gets a salary increase.

Syntax
UPDATE table_name
SET column = value
WHERE condition;

Example 1
Increase Rahul's salary.
UPDATE employees
SET salary = 55000
WHERE id = 1;
Check:
SELECT * FROM employees;
Rahul's salary is now 55000.

Update Multiple Columns
UPDATE employees
SET salary = 60000,
    department = 'Development'
WHERE id = 2;
Amit's salary and department are both updated.

🚨 Why WHERE is Important
Suppose you accidentally write:
UPDATE employees
SET salary = 100000;
There is no WHERE clause.
What happens?
Every employee's salary becomes:
100000
100000
100000
100000
100000
100000
This is a common real-world mistake.
Always check your WHERE clause before running an UPDATE.

3. DELETE
What is DELETE?
DELETE removes rows from a table.
The table remains.
Only the selected rows are removed.

Syntax
DELETE FROM table_name
WHERE condition;

Example
Delete employee with id = 4.
DELETE FROM employees
WHERE id = 4;
Now:
SELECT * FROM employees;
Priya is gone.

🚨 DELETE Without WHERE
Suppose you run:
DELETE FROM employees;
What happens?
Every row is deleted.
The table still exists.
But it becomes empty.
employees

(no rows)
This is why WHERE is so important.

UPDATE vs DELETE
UPDATE
Changes existing rows.
Example:
UPDATE employees
SET salary = 65000
WHERE id = 3;
Neha still exists.
Only her salary changes.

DELETE
Removes rows completely.
DELETE FROM employees
WHERE id = 3;
Neha no longer exists in the table.

Practice Questions
Q1
Insert a new employee.
INSERT INTO employees
VALUES (9,'Karan',31,'Sales',52000);

Q2
Increase Rahul's salary to ₹60,000.
UPDATE employees
SET salary = 60000
WHERE name='Rahul';

Q3
Change Amit's department to Finance.
UPDATE employees
SET department='Finance'
WHERE name='Amit';

Q4
Increase Rohit's age by 1 year.
UPDATE employees
SET age = age + 1
WHERE name='Rohit';
Notice this:
age = age + 1
updates the existing value instead of replacing it with a fixed number.

Q5
Delete employee Priya.
DELETE FROM employees
WHERE name='Priya';

Q6
Delete employee whose id is 7.
DELETE FROM employees
WHERE id=7;

Q7
Add another employee.
INSERT INTO employees
VALUES (10,'Pooja',26,'HR',47000);

Q8
Increase every employee's salary by ₹5,000.
UPDATE employees
SET salary = salary + 5000;
Notice there is no WHERE, so every row is updated. This is intentional here.

Q9

WHERE department='HR';

Q10
Display all remaining employees.

Interview Questions
1. What is DML?
Answer:
DML (Data Manipulation Language) is used to insert, update, delete, and retrieve data from database tables.

2. What is INSERT?
Answer:
INSERT adds new rows to a table.

3. What is UPDATE?
Answer:
UPDATE modifies existing rows in a table.

4. What is DELETE?
Answer:
DELETE removes rows from a table while keeping the table structure.

5. Why is WHERE important in UPDATE?
Answer:
Without WHERE, every row in the table is updated.

6. Why is WHERE important in DELETE?
Answer:
Without WHERE, every row in the table is deleted.

7. What is the difference between DELETE and DROP?
