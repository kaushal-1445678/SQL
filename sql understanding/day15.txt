What is a Primary Key?
A Primary Key is a column whose value is unique and cannot be NULL.
Example:
CREATE TABLE departments (
    department_id INTEGER PRIMARY KEY,
    department_name TEXT
);
Example data:
department_id	department_name
101	IT
102	HR
103	Sales
Notice:
101 appears only once
102 appears only once
103 appears only once
✅ This is a Primary Key.
What is a Foreign Key?
A Foreign Key is a column that refers to the Primary Key of another table.
Employees table:
emp_id	name	department_id
1	Rahul	101
2	Amit	102
Here,
department_id
is a Foreign Key because it points to the Departments table.
Relationship:
Departments
department_id (PK)

↓

Employees
department_id (FK)

What is INNER JOIN?
An INNER JOIN returns only the rows where there is a matching value in both tables.
Think of it like this:
Employees                    Departments

Rahul ----101----------> IT
Amit  ----102----------> HR
Neha  ----101----------> IT
Priya ----103----------> Sales
Vikas ----104----------> Finance
Rohit ----102----------> HR
SQL matches:
101 ↔ 101
102 ↔ 102
103 ↔ 103
104 ↔ 104
INNER JOIN Syntax
SELECT columns
FROM table1
INNER JOIN table2
ON table1.column = table2.column;
First INNER JOIN
SELECT
e.name,
d.department_name
FROM employees_join e
INNER JOIN departments d
ON e.department_id = d.department_id;
Output
name	department_name
Rahul	IT
Amit	HR
Neha	IT
Priya	Sales
Vikas	Finance
Rohit	HR
Understanding ON
This line:
ON e.department_id = d.department_id
means:
Compare

Employees.department_id

with

Departments.department_id
If equal:
101 = 101 ✅

Join them.
Why Use Aliases?
Without aliases:
SELECT employees_join.name,
departments.department_name
FROM employees_join
INNER JOIN departments
ON employees_join.department_id =
departments.department_id;
Works, but it's long.
Instead:
employees_join → e

departments → d
Then:
SELECT
e.name,
d.department_name
FROM employees_join e
INNER JOIN departments d
ON e.department_id = d.department_id;
Cleaner and easier to read.

Common Mistakes
❌ Mistake 1: Forgetting the ON condition
Wrong:
SELECT *
FROM employees_join
INNER JOIN departments;
This is invalid because SQL doesn't know how the tables are related.
Correct:
SELECT *
FROM employees_join
INNER JOIN departments
ON employees_join.department_id = departments.department_id;
❌ Mistake 2: Ambiguous column names
If both tables have a column called department_id:
Wrong:
SELECT department_id
FROM employees_join
INNER JOIN departments
ON department_id = department_id;
SQL doesn't know which department_id you mean.
Correct:
SELECT e.department_id
FROM employees_join e
INNER JOIN departments d
ON e.department_id = d.department_id;
❌ Mistake 3: Forgetting aliases in larger queries
Aliases make long join queries much easier to read and maintain.
Interview Questions (with Answers)
1. What is a JOIN?
Answer:
A JOIN combines rows from two or more tables using a related column.
2. What is an INNER JOIN?
Answer:
An INNER JOIN returns only the rows where matching values exist in both tables.
3. Why do we use INNER JOIN?
Answer:
To retrieve related data stored across multiple tables, such as employee details and department names.
4. What is the difference between a Primary Key and a Foreign Key?
Answer:
Primary Key: Uniquely identifies each row in a table.
Foreign Key: References the Primary Key of another table to create a relationship.
5. What happens if there is no matching row in an INNER JOIN?
Answer:
That row is not included in the result.
Quick Cheat Sheet
-- Basic INNER JOIN
SELECT e.name, d.department_name
FROM employees_join e
INNER JOIN departments d
ON e.department_id = d.department_id;

-- INNER JOIN with WHERE
SELECT e.name, d.department_name
FROM employees_join e
INNER JOIN departments d
ON e.department_id = d.department_id
WHERE d.department_name = 'IT';

-- INNER JOIN + GROUP BY
SELECT d.department_name, COUNT(*)
FROM employees_join e
INNER JOIN departments d
ON e.department_id = d.department_id
GROUP BY d.department_name;

-- INNER JOIN + HAVING
SELECT d.department_name, COUNT(*)
FROM employees_join e
INNER JOIN departments d
ON e.department_id = d.department_id
GROUP BY d.department_name
HAVING COUNT(*) > 1;
